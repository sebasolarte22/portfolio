Educational LMS Backend API

Production-ready REST API for an educational platform. The system manages authentication, courses, enrollments, lesson progress and favorites while implementing caching, secure authentication and a scalable backend architecture.

  • Node.js
  • Express
  • PostgreSQL
  • Redis (caching)
  • Docker
  • JWT Authentication
  • Refresh Token Rotation
  • Role-based Access Control
  • Structured Logging
  • Integration Testing
  • AI API Integration

Designed and implemented the backend architecture following a service-based structure (controllers → services → infrastructure). Implemented: • secure authentication with refresh token rotation • Redis cache-aside pattern with cache invalidation • role-based access control • structured logging with Winston • integration tests using Jest and Supertest The system is containerized with Docker and deployed to the cloud.
