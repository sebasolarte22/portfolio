Knowledge Hub API

Production-grade event-driven REST API for managing developer knowledge resources. Built with NestJS using a fully modular architecture with 12 domain modules, covering auth, resources, categories, favorites, users, storage, queues, events, redis, logger, prisma and common utilities.

API REST event-driven de nivel productivo para gestionar recursos de conocimiento para desarrolladores. Construida con NestJS usando una arquitectura completamente modular con 12 modulos de dominio, cubriendo auth, resources, categories, favorites, users, storage, queues, events, redis, logger, prisma y common.

Key Features

  • JWT access and refresh token rotation with Redis blacklist
  • Multi-session management and token revocation
  • BullMQ queues with retry strategies and dead-letter queue
  • Domain event publishing via internal EventBus
  • Versioned Redis cache-aside pattern
  • AWS S3 file uploads with presigned URLs
  • Full-text search with cursor-based pagination
  • Favorites system with per-user state
  • RBAC with role-based guards
  • Helmet, rate limiting and input sanitization

Caracteristicas Clave

  • Rotacion de tokens JWT access y refresh con blacklist en Redis
  • Gestion multi-sesion y revocacion de tokens
  • Colas BullMQ con reintentos y dead-letter queue
  • Publicacion de eventos de dominio via EventBus interno
  • Patron cache-aside versionado con Redis
  • Subida de archivos a AWS S3 con presigned URLs
  • Busqueda full-text con paginacion por cursor
  • Sistema de favoritos por usuario
  • RBAC con guards por rol
  • Helmet, rate limiting y sanitizacion de entradas
